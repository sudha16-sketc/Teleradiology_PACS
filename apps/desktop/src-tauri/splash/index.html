This desktop client is not connected to an Axis deployment

Axis Desktop loads the PACS from a running Axis deployment, so it needs to be told where that deployment is. Nothing is guessed, and in particular it will never fall back to a localhost address.

Set the deployment URL in one of these ways, then relaunch:

1. Environment variable (per launch, wins over everything):
     AXIS_DESKTOP_SERVER_URL=https://pacs.example.org

2. Per-user config file:
     %APPDATA%\com.axis.teleradiology.pacs\desktop.json

     { "serverUrl": "https://pacs.example.org" }

The deployment must be running the Axis web client and the NestJS API.
